## 👨‍💻 Sobre mim

Atuo no desenvolvimento de soluções backend, integrações e automações
voltadas para problemas reais de operação.

Tenho experiência construindo sistemas desde a modelagem do banco de dados
até a publicação em produção, incluindo autenticação, arquitetura
multi-tenant, APIs, filas, integrações e infraestrutura com Docker.

Atualmente, meus principais focos são:

- Desenvolvimento de APIs com Python e FastAPI;
- Plataformas SaaS com isolamento de dados por empresa;
- Integrações entre sistemas, webhooks e APIs externas;
- Automação de processos com n8n;
- Deploy e gerenciamento de aplicações em servidores Linux.

## 🚀 Projeto em destaque

### Baiano Feet — Plataforma SaaS de gestão comercial

Plataforma desenvolvida para centralizar a operação de lojas, reunindo
vendas, estoque, clientes, usuários e informações financeiras em um
ambiente multiempresa.

#### Principais recursos

- PDV responsivo;
- Controle de produtos e estoque;
- Gestão de clientes e vendas;
- Arquitetura multi-tenant;
- Isolamento de dados por empresa;
- Controle de acesso por usuário e perfil;
- Relatórios comerciais e financeiros;
- Integrações com serviços externos;
- Implantação em ambiente de produção com Docker.
